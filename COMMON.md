### Техническое задание: Реализация торгового сигнального модуля

#### Общая цель
Разработать Python-скрипт для подключения к брокерскому API, загрузки исторических ценовых данных, расчета технических индикаторов и генерации сигнала на покупку на основе пересечения скользящих средних (EMA).

#### Требования к реализации

**1. Управление конфигурацией**
- Хранить параметры подключения к API брокера (API key, secret, endpoint, account ID) в файле `.env`.
- Создать файл `config.py`, который парсит `.env` (например, через `python-dotenv`) и предоставляет переменные для использования в коде.
- **Пример содержимого `.env`** (шаблон):
  ```
  API_KEY=your_api_key_here
  API_SECRET=your_secret_here
  API_BASE_URL=https://api.broker.com
  ```

**2. Инициализация клиента и проверка соединения**
- Используя предоставленный брокером SDK/библиотеку (или REST API запросы), инициализировать клиент с данными из `config.py`.
- Выполнить проверку подключения к сервису (например, запрос к методу `ping`, или получение информации об аккаунте).
- В случае ошибки соединения — вывести сообщение и завершить выполнение.

**3. Загрузка данных о свечах (OHLC)**
- Реализовать функцию загрузки свечей с параметрами по умолчанию, с возможностью переопределения.
- **Параметры по умолчанию:**
  - Количество свечей: `5`
  - Гранулярность (таймфрейм): `M15` (15 минут)
  - Инструмент: `GBP_JPY`. Если инструмент недоступен — использовать `EUR/AED` (евро-дирхам ОАЭ) или любой другой валютный инструмент, доступный в песочнице/демо-счете брокера.
  - Тип цены: `ask` (цена спроса)
- Результат: сырые данные в формате JSON/объекте ответа API.

**4. Форматирование данных с помощью Pandas**
- Из ответа API извлечь список свечей. Пример ожидаемой структуры одной свечи (ФОРМАТ И КЛЮЧИ МОЖЕТ БЫТЬ ДРУГИМ):
  ```python
  {
    'complete': True,   # bool: завершена ли свеча
    'volume': 2752,     # int: объем
    'time': '2025-04-25T15:45:00',  # str: ISO формат
    'ask': {            # dict: цены ask (спрос)
      'o': '191.473',   # open
      'h': '191.657',   # high
      'l': '191.454',   # low
      'c': '191.624'    # close
    }
  }
  ```
- **Важно:** использовать **только завершенные свечи**, где `'complete': True`. Незавершенные отбросить.
- Запросить около 500 строк данных (для надежного расчета индикаторов загрузить не менее 200 свечей).
- Преобразовать данные в `pandas.DataFrame` со следующими столбцами:
  - `'time'` — преобразовать в тип `datetime` (использовать `pd.to_datetime`)
  - `'open'` — взять из `item['ask']['o']`, привести к `float`
  - `'high'` — из `item['ask']['h']`, `float`
  - `'low'` — из `item['ask']['l']`, `float`
  - `'close'` — из `item['ask']['c']`, `float`

**5. Визуализация данных**
- Используя библиотеку `matplotlib.pyplot as plt`, построить график цены закрытия (`close`).
- Команда: `plt.plot(dataFrame['close'])` и `plt.show()`.
- График отображается для визуального контроля загруженных данных.

**6. Расчет индикаторов (функция `calculate_indicators`)**
- Создать функцию `calculate_indicators(df: pd.DataFrame) -> pd.DataFrame`, которая на вход принимает DataFrame из п.4 и возвращает его же с добавленными колонками индикаторов.
- Использовать библиотеку `pandas_ta as ta`.
- Добавить в DataFrame:
  - `df['EMA_5'] = ta.ema(df['close'], length=5)`
  - `df['EMA_8'] = ta.ema(df['close'], length=8)`
  - `df['ATR_14'] = ta.atr(df['high'], df['low'], df['close'], length=14)`
- Обработать возможные `NaN` значения (первые N строк будут пустыми — их можно проигнорировать при анализе сигналов).

**7. Генерация сигнала (функция `ema_crossover`)**
- Создать функцию `ema_crossover(df: pd.DataFrame)`, которая принимает обогащенный индикаторами DataFrame.
- Внутри функции задать коэффициент тейк-профита: `tp_ratio = 1.5`.
- **Логика выявления пересечения:**
  - Взять **две последние завершенные свечи**:
    ```python
    last_candle = df.iloc[-1]
    previous_candle = df.iloc[-2]
    ```
  - **Условие сигнала на покупку (Buy signal):**
    ```
    (last_candle['EMA_5'] > last_candle['EMA_8']) and
    (previous_candle['EMA_5'] < previous_candle['EMA_8'])
    ```
  - Если условие истинно, вывести в консоль строку: `print('Buy signal')`.
  - Дополнительно (опционально): вывести значения индикаторов на последних свечах для отладки.

#### Ожидаемый результат работы программы
- Успешное подключение к брокеру через API.
- Загрузка и корректное форматирование не менее 500 свечей.
- Построение графика цены закрытия.
- Расчет EMA(5), EMA(8), ATR(14) и добавление их в DataFrame.
- Вывод в консоль `'Buy signal'` при возникновении пересечения "бычьей" кроссовки (EMA5 снизу вверх пересекает EMA8) на последних двух свечах. При отсутствии сигнала — никакого вывода (или информационное сообщение об отсутствии).

#### Примечания для LLM
- Учитывай, что названия ключей в ответе API могут отличаться от примера. Необходимо адаптивно извлекать поля `time`, `ask`, `complete`, `o`, `h`, `l`, `c` из фактической структуры ответа.
- Используй обработку исключений при работе с сетью, API, файлами и преобразованиями данных.
- Соблюдай принципы чистой архитектуры: разделение на модули (config, api_client, data_processing, indicators, signal_generator).
